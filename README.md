# ResearchHub

A desktop prototype of an Arabic research-sharing platform, built with Python and Tkinter. It lets a student sign in, browse research papers, manage references and upload their own work, all from one window.

> **Status:** UI prototype. Login, search and uploads use sample data; there is no database or backend yet.

## Features

- **Accounts:** sign in, create an account and reset a password.
- **Home dashboard:** quick access to the platform's main features.
- **Smart search:** search for research papers and view results.
- **Upload research:** share your own papers on the platform.
- **Reference manager:** keep technical references in one place and edit them.
- **Profile page:** view account details and log out.

## Tech stack

- Python 3
- Tkinter (built into Python, no extra packages needed)
